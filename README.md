### &nbsp;&nbsp;📌 &nbsp; Project Deep Dives

<details>
<summary><b>🧠 MindBERT — Mental Health Condition Classifier &nbsp;·&nbsp; <a href="https://github.com/Ankita-Kumari0309/MindBERT-Mental-Health-Classifier">View Repository ↗</a></b></summary>
<br/>

> Classifies 7 mental health conditions — Depression, Anxiety, Bipolar, Suicidal Ideation & more — from social media text using **DistilBERT**.

```
Dataset  →  53,000+ Reddit & Twitter posts  (7 classes)
Model    →  Fine-tuned DistilBERT  (HuggingFace Transformers + PyTorch)
Result   →  79.82% accuracy  ·  Weighted F1: 0.80
Baseline →  Beat best classical model (Linear SVC) by ~4%
```

**Models Benchmarked:** `DistilBERT` · `Logistic Regression` · `Linear SVC` · `Random Forest (TF-IDF bigrams)`

**Stack:** `HuggingFace Transformers` · `PyTorch` · `Scikit-Learn` · `NLTK` · `Pandas` · `NumPy` · `Matplotlib` · `Seaborn`

</details>

<details>
<summary><b>📰 News Intelligence Bot — RAG + LLM Pipeline &nbsp;·&nbsp; <a href="https://github.com/Ankita-Kumari0309/news-intelligence-bot">View Repository ↗</a></b></summary>
<br/>

> Real-time conversational AI that fetches live news, embeds it into a vector store, and returns **cited, hallucination-free answers** with sentiment analysis.

```
Data     →  Live news via NewsAPI + text-embedding-ada-002 embeddings
Memory   →  Multi-turn via LangChain ChatMessageHistory
Feature  →  Automated contradiction detection  (high / medium / low severity)
Deploy   →  Azure App Service  ·  FastAPI backend  ·  Premium dark UI
```

**Stack:** `LangChain` · `Azure OpenAI (GPT-4o)` · `ChromaDB` · `FastAPI` · `NewsAPI` · `Python`

</details>

<details>
<summary><b>🎫 HelpX — Multi-Agent IT Ticket Resolver &nbsp;·&nbsp; <a href="https://github.com/Ankita-Kumari0309/HelpX---IT-TicketResolver">View Repository ↗</a></b></summary>
<br/>

> Multi-agent system for automated IT support — classifies, routes, resolves, and escalates tickets — reducing manual effort by **~60%**.

```
Agents   →  Classifier · Knowledge Base · Notification  (Autogen + Azure OpenAI)

UI       →  Interactive Streamlit dashboard + automated email escalation
Result   →  ~60% reduction in manual intervention
```

**Stack:** `Autogen` · `Azure OpenAI` · `Azure Cognitive Search` · `Streamlit` · `Python`
